# Research plan

1. Collect a large tick sample without trading.
2. Compare 3/5/7/10/15 tick horizons.
3. Measure raw win rate, break-even rate, Wilson intervals, P/L, streaks and calibration.
4. Compare unfiltered candidate vs EPEL-filtered candidate.
5. Run walk-forward tests and an untouched out-of-sample period.
6. Only if an edge survives, investigate execution and risk management.
7. Do not add martingale to create an apparent edge.
